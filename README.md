# Design Thinking Class C — Portfolio

A one-page site for Design Thinking Class C (First Semester, 2026): a scroll story, a group showcase, the lecturer, students and their feedback.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
npm test
```

- Edit content in `src/data/site.ts`.
- The product spec is in `PRD.md`, the visual and motion spec in `DESIGN.md`, and the working notes in `CLAUDE.md`.
